# M8 Programme Design & Cost–Capital Frontier

## 讲解

**业务问题**：在所有候选方案里，哪些是有效的？管理层按不同风险偏好应该选哪个？推荐哪个？

**输入**：M4 的 OEP（决定层的美元条款）、M7 的逐方案指标。

**输出**：`programmes.csv`、`frontier.csv`、`outputs/recommendation.json`，以及 Hero chart 2（推荐方案 gross vs net AEP）和 Hero chart 3（全部方案、前沿、三个选择）。

**方案网格**
- q ∈ {0, 10%, 20%}
- 起赔重现期 {5, 10, 20, 50} × 耗尽重现期 {50, 100, 200, 250}，且耗尽 > 起赔
- 单层，或在 1-in-50 / 1-in-100 处切成两层 tower
- c ∈ {80%, 100%}，n ∈ {0, 1}
- 再加 no RI 和纯 QS 10% / 20%

共 387 个方案。起赔点 = (1 − q) × OEP⁻¹(1/RP)，按 USD 10m 取整。

**关键规则**
- 被支配：存在另一个方案，成本不更高、EC 不更高，且至少一项严格更低。
- 前沿上取下凸包；相邻两点的边际 CoC = Δnet cost / Δrelief。
- Budget-first：前沿上 relief ≥ 25% 的最便宜方案。
- Balanced(h)：沿凸包从 no RI 往上走，边际 CoC 超过 h 之前的最后一点。
- Protection-first：前沿上 EC 最低的方案。

**判断**：推荐 Balanced(10%)，除非结果明显不合理。每个方案的美元条款固定下来，M9 的压力测试重估的是同一批合同。

**常见错误**：
- 在美元上拍脑袋设层。
- 用平均 implied CoC 而不是边际 CoC 选点：平均值会掩盖最后一段保护很贵这件事。

## 结果

- 387 个网格 ID → 255 个不同合同（D13）。79 个在前沿上，凸包 7 个点：

| 凸包点 | net cost（USD m） | EC_net（USD bn） | relief % | 边际 CoC |
|---|---|---|---|---|
| no RI | 0 | 25.3 | 0% | – |
| QS 20% | 287 | 20.3 | 20% | 5.7% |
| QS20 + 1-in-50 到 1-in-100，80% | 583 | 15.1 | 40% | 5.7% |
| 同上，100% | 657 | 13.8 | 46% | 5.8% |
| QS20 + 1-in-20 到 1-in-100，100% | 905 | 9.6 | 62% | 5.9% |
| **QS20 + 1-in-5 到 1-in-200，80%（Balanced 10%）** | **1,215** | **4.6** | **82%** | **6.2%** |
| 同上，100%（Protection-first） | 1,447 | 2.3 | 91% | 10.1% |

- **Budget-first**：`QS0_A50_E100_T0_C80_R0`（1-in-50 到 1-in-100，80%），relief 25.6%，net cost USD 370m。
- **Balanced(8%) = Balanced(10%)** = `QS20_A5_E200_T0_C80_R0`；**Balanced(12%)** = Protection-first。
- **推荐方案**：
  - QS 20%，XoL 一层：起赔 USD 990m（QS 后，1-in-5），耗尽 21,310m（1-in-200），分出 80%，不带 reinstatement。
  - 预付再保费合计 USD 1,966m，期望赔回 752m，net cost USD 1,215m / 年。
  - 释放资本 USD 20.7bn（82%），implied CoC 5.9%。
- **怎么理解"买这么多"**：
  - Balanced 规则等价于最小化"总风险成本 = 再保 net cost + h × EC_net"：
    - gross：0 + 10% × 25.3bn = 2.53bn
    - Budget-first：0.37 + 1.89 = 2.26bn
    - Balanced：1.21 + 0.46 = 1.68bn
  - 按 10% 的股东资本成本，这个组合 gross 状态下的资本成本（2.5bn）已经超过它全部的期望利润（保费 2.59bn − 期望损失 1.55bn ≈ 1.0bn）。只要再保人按 5% 加费用收资本费，把尾部转出去就更便宜。
  - 这与 NFIP 本身"保费撑不起巨灾尾部"的现实一致。
  - 推荐的再保费占组合保费的 76%，商业上很激进。备忘录明说这一点，并用 M9 的 d = 1 敏感性说明：结论取决于再保人的分散化假设。
- 1-in-200 和 1-in-250 耗尽的合同相同，都在事件上限处，这是 M4 发现的上限效应。

## Teach-back

1. 为什么用重现期而不是美元来设计层？
2. 什么叫被支配的方案？
3. 为什么不宣布唯一最优？你怎么在前沿上选点？
4. hurdle 从 10% 改到 12%，推荐会怎么变？为什么？

**参考答案**

1. 层应该对准风险本身：1-in-10 起赔的意思是十年一遇的事件开始赔，这在任何组合规模下都可比，也能和 FEMA、巨灾债券的 AP 对齐。
2. 另有方案更便宜（或一样贵）且资本更低（或一样），至少一项严格更好。理性的管理层不会选被支配的方案。
3. 最优取决于预算、风险偏好和资本成本，这些是管理层的决定。前沿给出所有有效选项，边际 CoC 规则把"多买一段保护是否比股东资本便宜"变成可以讨论的数字。
4. hurdle 提高意味着股东资本更贵，更多段保护的边际 CoC 低于 hurdle，所以沿凸包走得更远，推荐更多保护（更低起赔或更高耗尽）。hurdle 降到 8% 则相反。
