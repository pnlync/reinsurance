# M0 Setup

## 讲解

**业务问题**：还不做业务。搭一个可复现、参数集中管理的骨架，让后面每个数字都能追溯到 config 和代码。

**输入**：SPEC §5 的全部参数。**输出**：`pyproject.toml`（uv、Python 3.12）、`src/floodcat/` 包骨架、`Makefile`（12 个 target）、6 个 `config/*.yaml`。

**关键规则**：参数只在 yaml 里；只有 `floodcat.data.load` 能读原始数据，原始数据只有一个入口，冻结后不会被别处悄悄改用。

**判断**：u₀ 先写 100m，M2 看事件列表后确认。金额从 M2 起统一用 USD m（D3）。

**常见错误**：代码写死数字；层网格没过滤耗尽点 ≤ 起赔点（1-in-50 起赔 + 1-in-50 耗尽就是无效层）。

## 测试结果

16 PASS：6 个 config 全部加载并通过校验；SPEC 数值抽查；层组合 16 个中过滤掉 (50, 50) 剩 15 个；7 类非法值被拒绝；除 `load.py` 外没有文件包含 `data/raw`。
