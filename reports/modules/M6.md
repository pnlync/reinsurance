# M6 Reinsurance Pricing

## 讲解

**业务问题**：每一层（和每个 QS 比例）该收多少钱？

**输入**：
- M5 在 100,000 个模拟年上的逐年层赔付 C 和恢复比例 f
- 同一套函数在 2009–2023 历史 as-if 年上的赔付（burning cost）
- 定价参数：CoC_R = 10%，d = 0.5，XoL 费用率 10%，QS 费用率 3%

**输出**：`outputs/tables/layer_pricing.csv`（每层：AP、EP、碰到年数、burning cost、EL、SD、TVaR99.5、K_R、资本费、保费、预期补费、ROL、倍数）、`qs_pricing.csv`、`programmes.csv`（全部方案的美元条款），以及图 `m6_rol_vs_ap.png`。

**关键公式**

- EL = mean(C)；K_R = TVaR99.5(C) − EL；资本费 = CoC_R × d × K_R
- 预期总保费收入 target = (EL + 资本费) / (1 − e)
- 预付保费 P = target / (1 + rate × mean(f))：补费是再保人的额外收入，所以预付可以更低
- ROL = P / (cL)；倍数 = (P + 预期补费) / EL
- QS：P_QS = (q E[L] + CoC_R d K_QS) / (1 − e_QS)

**判断**

- 定价用模型 EL，burning cost 只并排展示。
- 资本用 TVaR 而不是 VaR：远端层 AP < 0.5% 时 VaR99.5(C) = 0，K_R 会变成负数。
- d 是再保人的分散化：同一层放进全球再保人的组合里，边际资本远低于单独持有时的资本。

**常见错误**

- 有 reinstatement 时仍按 P = (EL + 资本费)/(1 − e) 收预付，等于把补费重复收了一次。
- 把 burning cost = 0 当成风险为 0。

## 结果

- 144 个不同的层（按 q、起赔、耗尽、c、n 区分）和 2 个 QS 比例全部定价。255 个不同合同的美元条款写在 `programmes.csv`。
- 例子（QS 0%、c = 100%、一次 reinstatement）：

| 层（重现期） | 起赔–耗尽（USD m） | AP | 碰到年数 | Burning cost | 模型 EL | 保费 | ROL | 倍数 |
|---|---|---|---|---|---|---|---|---|
| 1-in-5 到 1-in-50 | 1,240–10,000 | 20% | 3 | 843 | 510 | 1,071 | 12.2% | 2.2× |
| 1-in-10 到 1-in-100 | 2,480–18,220 | 10% | 2 | 612 | 440 | 1,341 | 8.5% | 3.1× |
| 1-in-20 到 1-in-200 | 4,590–26,640 | 5% | 2 | 331 | 353 | 1,587 | 7.2% | 4.6× |
| 1-in-50 到 1-in-200 | 10,000–26,640 | 2% | 0 | 0 | 183 | 1,110 | 6.7% | 6.1× |
| 1-in-100 到 1-in-200 | 18,220–26,640 | 1% | 0 | 0 | 67 | 536 | 6.4% | 8.1× |

- 性质检验全部通过：固定耗尽点时 ROL 随起赔点升高而下降；AP 越低倍数越高；保费 ≥ EL；net cost = 费用 + CoC_R·d·K_R。
- **低层的 burning cost 高于模型 EL**（1-in-5 层 843 vs 510）。15 年里有 Harvey、Ian、2016 年路易斯安那三个大事件，经验偏重。这与 M3 QQ 图上最大两点在对角线之上是同一件事。统计上仍在抽样误差之内，但它意味着模型价格可能偏低，要写进备忘录。
- 远端层 burning cost 为 0，而模型 EL > 0，这正是需要巨灾模型的原因。
- QS：10% 比例保费 USD 298m（分出 EL 155m + 资本费 135m + 费用），net cost 143m。

## Teach-back

1. burning cost 和模型 EL 各自什么时候可信？
2. 为什么 premium ≠ EL？为什么远端层倍数更高？
3. 为什么用 TVaR 计再保人资本？
4. d 代表什么？它为什么决定"再保值不值得买"？

**参考答案**

1. 低层经常被触及，15 年里碰到多次，经验和模型都可信，两者应接近。远端层历史上可能一次都没碰到，burning cost = 0，只能靠模型。
2. 再保人要为这层持有资本、负担费用。远端层 EL 很小，但 TVaR 很大（一旦赔就赔满），所以资本费相对 EL 的比例高，倍数就高。
3. TVaR 对所有层都 ≥ EL，而且随层连续变化。VaR 在 AP 低于 0.5% 的层上为 0，会让 K_R 为负、保费低于 EL。
4. d 是这层在再保人分散组合里的边际资本占单独资本的比例。若 d = 1，数学上可证 implied CoC 永远 ≥ CoC_R + 费用，再保永远比股东资本贵。正因为分散化让再保人的真实资本成本更低，分出人才有理由买再保。
